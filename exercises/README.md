# exercises

- `basics/` - beginner exercises. From the practicepython.org exercise site, the ProgModX course (lists, primes, strings), plus `ITfagdag.py` (quiz helper) from the IT2 school course.
- `algorithms/` - short judged problems (reverse, closest points, Collatz, FizzBuzz). From the coding exercises at the Machine Learning Camp.
- `recursion/` - recursive sum, binomial, tribonacci, list comparison. From the coding exercises at the Machine Learning Camp.
