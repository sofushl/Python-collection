# python-collection

Old Python work from school courses, a coding camp and online exercises. Comments are mostly Norwegian.

| Folder           | Content                                                                  |
|------------------|--------------------------------------------------------------------------|
| `games/`         | Pygame and terminal games                                                |
| `simulations/`   | Physics and epidemic simulations, including the snowboard jump simulator |
| `data-analysis/` | Plotting, statistics, weather data, maps                                 |
| `math/`          | Algebra, calculus, small number programs                                 |
| `microbit/`      | micro:bit programs                                                       |
| `exercises/`     | Small practice exercises                                                 |
| `projects/`      | Larger programs                                                          |
| `tools/`         | Small utility scripts                                                    |

Install libraries with `pip install -r` per folder, or use `pyproject.toml` for everything.
Some scripts load data or images with paths from the original folders. Run them from their own folder and fix paths where needed.
