# simulations

- `jumpsim/` - snowboard jump simulator. Made in the Programming and Simulating course.
- `physics/` - projectile, billiards (`Vektor.py` is its vector helper), pendulum. Includes the small data files for the projectile plot. From the Physisc, Math, and ProgModX course and an online exercise site.
- `epidemics/` - SIR model fitted to influenza data. From the ProgModX course.
